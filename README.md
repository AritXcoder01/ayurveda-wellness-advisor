# 🌿 AyurVeda Life - Personalized Wellness & Dosha Advisor

## ✨ Key Features

- **🔒 Authentication & Security Verification Modal**: User registration with age/gender controls, client-side session management via `localStorage`, and interactive 6-digit OTP security verification.
- **📋 15-Question Assessment Engine**: Comprehensive questionnaire analyzing physical build, skin, hair, digestion, sleep, energy, stress, communication, exercise, weather, spending, taste cravings, and core disposition.
- **📊 Interactive SVG Dosha Chart**: Custom donut chart visualizer calculating Vata, Pitta, and Kapha score ratios and identifying single or dual-dominant dosha profiles.
- **🍲 Personalized Diet & Yoga Guidelines**: Custom diet recommendations (foods to favor & avoid), 5 targeted therapeutic yoga poses with benefits, Dinacharya schedules, and sleep hygiene.
- **✍️ Daily Dinacharya Habit Tracker**: Interactive check-ins for morning lemon water, Abhyanga oil massage, tongue scraping, yoga, and early sleep with a **🔥 Live Streak Counter**.
- **🌿 Herbal & Recipe Repository**: Searchable directory of 6 classical Ayurvedic herbs (*Ashwagandha, Triphala, Brahmi, Tulsi, Shatavari, Turmeric*) and culinary healing recipes (*Kitchari, Golden Milk, Cooling Mint Drink, CCF Tea*).
- **💨 Guided Pranayama Breathing Timer**: Interactive visual breathing sphere with phase timers for *Nadi Shodhana*, *Sheetali*, and *Kapalabhati*.
- **⚡ 24-Hour Acute Imbalance Reset Mode**: 1-click diagnostic tool for acute daily imbalances (Vata anxiety, Pitta heat, Kapha sluggishness) with 24-hour reset protocols.
- **📄 Printable Wellness Report Card**: Clean, print-ready diagnostic report formatted for PDF export via `window.print()`.
- **📱 Ultra-Responsive & Mobile First**: Glassmorphic nature design (`#051F20`, `#0B2B26`, `#163832`, `#8EB69B`, `#FF9500`), ultra-thin color-matched scrollbars, and a left-side mobile navigation drawer.

## 🛠️ Technology Stack

- **Frontend Core**: React 18 (Hooks, Context API)
- **Build Tool**: Vite 8
- **Styling**: Modern CSS variables, glassmorphism, responsive media queries, custom SVG charts
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Outfit* & *Inter*)
- **Data Persistence**: Browser `localStorage` (Zero external APIs required)

## 💻 Installation & Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/your-username/ayurveda-wellness-advisor.git

# 2. Navigate to project directory
cd ayurveda-wellness-advisor

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open `http://localhost:5173/` in your browser.
